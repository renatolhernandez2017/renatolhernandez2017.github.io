# Portfólio profissional — Renato Hernandez

Site estático pronto para GitHub Pages.

## Publicação

Copie os arquivos da pasta para a raiz do repositório `renatolhernandez2017.github.io`, faça commit e push na branch publicada pelo GitHub Pages. Em Settings > Pages, confirme a origem de publicação.

## Revisar antes de publicar

- Conferir autorização e precisão das descrições dos projetos.
- Atualizar o currículo em `files/Renato Hernandez 2025.pdf` (arquivo original preservado).
- Conferir telefone, e-mail, LinkedIn e domínio canônico.
- Quando houver domínio próprio, atualizar canonical, Open Graph, sitemap e robots.txt.
- Submeter sitemap ao Google Search Console depois da publicação.
